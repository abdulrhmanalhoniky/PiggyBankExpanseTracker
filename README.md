# Expense Tracker Application

A lightweight, high-performance cross-platform desktop/mobile expense management application built with Python, KivyMD, and SQLite. Designed with a lighy UI can be changed to dark mod if the user wanted  to track, categorize, and manage daily financial records smoothly without heavy asset overhead.

## 🛠️ Technologies Used
* **Python** - Core application logic and data handling.
* **Kivy / KivyMD** - Modern Material Design UI framework ensuring smooth, native-like rendering via OpenGL without heavy image assets.
* **SQLite / SQLite3** - Local, reliable embedded database for persistent financial record storage.

## 📌 Key Features
* **Lightning-Fast UI:** Built entirely programmatically with KivyMD components for instant loading and zero lag.
* **Smart Expense Tracking:** Easily input amounts and descriptions to categorize daily spending.
* **Data Persistence:** Automatically saves all transactions locally using an integrated SQLite database.
* **Cross-Platform Ready:** Designed to execute seamlessly across multiple operating systems.
